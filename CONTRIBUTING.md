# Contributing to NikaBoy

Thanks for your interest in improving NikaBoy! We welcome feedback, design improvements, and modifications.

## How to Contribute

### Reporting Issues / Design Feedback

Instead of "bugs," we track **design improvements** and **hardware feedback**:

- Check existing [Issues](https://github.com/xxshindowxx/NikaBoy/issues) first
- Create an issue describing:
  - **What needs improvement** (e.g., "D-pad is too small")
  - **Why it's a problem** (e.g., "Hard to press accurately")
  - **Photos/videos** if possible
  - **Your suggestions** for fixing it

### Examples of Good Issues:
- "Button spacing feels cramped"
- "D-pad could be larger for easier input"
- "Battery cover is hard to remove"
- "Screen positioning could be better"
- "Case design needs better grip"
